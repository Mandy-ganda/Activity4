# Mandy's Portfolio (Laboratory Exercise 4)

## Run it
```
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000  (fonts load from Google Fonts, so stay online)

## Make it yours
- Edit the `PROFILE` dictionary at the top of `app.py` (bio, skills, interests, links).
- GitHub link: change `https://github.com/` to `https://github.com/your-username`.
- Photo: replace `static/img/mandy.jpg`.

## Pages
/ (home), /profile, /programs (area of circle and triangle), /linked-list, /contact
Every page extends `templates/base.html`, which holds the nav bar, theme toggle, particles, and cursor.
